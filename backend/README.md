# Backend — Python FastAPI Server

The backend acts as the bridge between the React frontend, Pinata/IPFS, and the Ethereum smart contract.

## Stack

| Library | Purpose |
|---------|---------|
| FastAPI | REST API framework |
| Uvicorn | ASGI server |
| Web3.py | Ethereum / smart contract interaction |
| Pinata API | IPFS file pinning |
| python-dotenv | Environment variable loading |
| python-multipart | File upload support |

## Project Structure

```
backend/
├── app/
│   ├── __init__.py
│   ├── main.py             ← FastAPI app + CORS setup
│   ├── routes.py           ← API endpoint definitions
│   ├── ipfs_service.py     ← Pinata upload logic
│   └── blockchain_service.py ← Web3.py contract calls
├── abi/
│   └── DocumentVerifier.json  ← Contract ABI (auto-generated by deploy script)
├── .env.example            ← Environment variable template
├── requirements.txt
└── README.md
```

## Setup

### 1. Create a virtual environment

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure environment variables

```bash
cp .env.example .env
```

Open `.env` and fill in:

| Variable | Description |
|----------|-------------|
| `PINATA_JWT` | JWT token from [Pinata](https://app.pinata.cloud/developers/api-keys) |
| `RPC_URL` | Blockchain node URL (`http://127.0.0.1:8545` for local Hardhat) |
| `CONTRACT_ADDRESS` | Address printed after running the deploy script |
| `PRIVATE_KEY` | Test wallet private key (from `npx hardhat node` output) |

### 4. Start the Hardhat local node and deploy the contract

```bash
# In the blockchain/ directory:
npx hardhat node
npx hardhat run scripts/deploy.js --network localhost
```

The deploy script automatically copies the ABI to `backend/abi/DocumentVerifier.json`.

### 5. Run the backend server

```bash
uvicorn app.main:app --reload
```

Server runs at: `http://localhost:8000`

Interactive API docs: `http://localhost:8000/docs`

## API Endpoints

### POST `/api/documents/register`
Register a new document.

Form data:
- `document_id` (string) — unique identifier
- `file` (file) — the document to upload

Response:
```json
{
  "success": true,
  "document_id": "DOC001",
  "cid": "bafybeig...",
  "ipfs_url": "https://gateway.pinata.cloud/ipfs/bafybeig...",
  "tx_hash": "0xabc...",
  "issuer": "0x123...",
  "message": "Document registered successfully"
}
```

### POST `/api/documents/verify`
Verify a document.

Request body:
```json
{ "document_id": "DOC001", "cid": "bafybeig..." }
```

Response:
```json
{ "verified": true, "status": "VALID", "message": "..." }
```

### GET `/api/documents/{document_id}`
Get document details from the blockchain.

### POST `/api/documents/revoke`
Revoke a document.

Request body:
```json
{ "document_id": "DOC001" }
```

## Common Issues

**`Cannot connect to blockchain node`**
→ Make sure `npx hardhat node` is running in the `blockchain/` directory.

**`PINATA_JWT is not set`**
→ Add your JWT to `backend/.env`.

**`ABI file not found`**
→ Run `npx hardhat run scripts/deploy.js --network localhost` first.

**`Document already registered`**
→ Each document ID can only be registered once on the blockchain.
